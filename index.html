촬영 결과

어포컬 나이트뷰

접안렌즈에 댄 폰의 깜깜한 화면을, 여러 프레임을 겹치고(스택) 밝기를 증폭해서 보이게 만듭니다. 대상 찾기 · 실시간 관측 · 스택 촬영까지 이 안에서 합니다.

  1. 카메라 켜기 → 권한 허용
  2. 위쪽 목록에서 메인 렌즈(후면 0)를 고르세요
  3. 최대 감도 → 망원경에 대고 자동 맞춤
  4. 스택 촬영 → 결과를 자동 맞춤으로 다듬고 저장
  5. 망원경을 움직인 뒤엔 누적 리셋

갤럭시 + 크롬 기준. 카메라는 https 주소에서만 켜집니다. 수동 ISO·셔터는 기기가 허용하는 범위 안에서만 조절됩니다.
